# A 股等非美时段品种的三轴适配（Non-US Session Adaptation）

## R — Reading (原文)

> "Asian Killzone 20:00–00:00; London Open 02:00–05:00; New York Open 07:00–10:00; London Close 10:00–12:00; Central Bank Dealers Range 14:00–20:00."（纽约时间，PDF p.156）

> 回避条件（PDF p.170）：利率公告、重要演讲、假日交易、全球事件……；Asian range > 15–20 点(ES) 时等纽约时段更安全（p.170–171）。

原书边界自述（`session-taboo-filter` 卡 B 段）：**「不用于加密货币等 24/7 品种（原书未适配）」**。

出处：Ch11 PDF p.155–180；Ch4 p.82–83；Ch9 p.116；Ch12 p.196。

⚠️ **本卡性质声明**：原书**没有**任何关于 A 股或其他非美时段市场的内容。以下第 2–5 节的适配规则是**本流水线的迁移约定**，由 2026-10-25 对宁波韵升（600366.SH）日线 433 根的实测暴露的问题驱动，**不是作者主张**。原书仅第 1 节的时段清单与回避清单是作者内容。

## I — Interpretation (自述)

ICT 三轴中「时间轴」是硬门：核心原则第 1 条「时间先于价格」，第 5 条「不是每天都有交易：硬门不过即空仓」。这套时间轴按纽约本地时间标定五个 Killzone，并以 FOMC/NFP 等美国事件构成禁忌日清单。

对 A 股这类市场，时间轴会**永久判不过**：五窗口按纽约时间划分，A 股交易时段（9:30–11:30、13:00–15:00，合计正好 4 小时）与之无对应关系；禁忌日清单是美国经济日历；PO3 的 Accumulation/Manipulation/Distribution 三段按纽约时段切分；Asian range 阈值 15–20 点是 ES 口径。若机械执行硬门，任何 A 股请求都会得到「不交易」——这不是分析结论，而是**工具与市场的错配**。

本卡的作用是**在时间轴前置做品种分流**：判定品种是否属原书标定范围；不属时，时间轴降级为「不可用，跳过」而非「硬门失败 → 空仓」，价格轴与结构轴照常执行，并显式声明置信度降级。关键区分是：**「时间轴不适用」不等于「今天不该交易」**。前者是工具边界，后者是分析结论；混淆两者会让整套方法在非美市场失效。

同时要防止反向误用：跳过时间轴会丢失 ICT 最有价值的部分（时段行为差异、事件回避、PO3 节奏），因此适配后的输出必须标注为降级判定，不能与美股品种的完整三轴输出同等对待。

## A1 — Application Example

**原书未提供案例**（原书无 A 股内容）。以下为本流水线 2026-10-25 的实测记录，数据来自公开行情接口，非作者案例、非回测结果。

宁波韵升（600366.SH）日线 433 根（2025-01-02 至 2026-10-23），收盘 10.54：

| 轴 | 未适配时的输出 | 按本卡适配后的输出 |
|---|---|---|
| 时间轴 | 周六休市 + 无 Killzone 对应 + 无美国日历 → **硬门不过 → 判「不交易」，下游全部停止** | 判定为「时间轴不适用（非美时段品种）」→ 跳过，不产生「不交易」结论 |
| 价格轴 | 未执行 | 40 日 dealing range 9.63–12.20，EQ 10.91，当前折价 −3.4%；20/40/60/120 日区间全在折价半区；低侧 SSL 10.00 已被 5 根 K 线扫取（10-15/16/19/20/23）后收回；DOL 按 ERL→IRL 交替指向 10.77–10.78 未回补 bearish FVG |
| 结构轴 | 未执行 | 2026-10-23 位移成立（实体 3.7× 均值、振幅 2.3× 均值、收在振幅 99%），但高点 10.55 < 摆动高 11.32 → **MSS 未成立**；位移未留 bullish FVG |
| 最终 | 「不交易」（假阴性：错把工具边界当分析结论） | 「偏向冲突 → 观望」，附失效条件（站上 11.32 带位移 / 跌破 9.63） |

实测暴露的核心问题：**同一份数据，未适配时输出的「不交易」与适配后输出的「观望」是两个不同性质的结论**——前者无信息量，后者带完整的依据链与失效条件。

## A2 — Future Trigger

情境：用户拿 A 股/港股/其他非美时段品种的图表要求 ICT 分析；问「ICT 能不能用在 A 股」；问「为什么你说不能交易」但品种并非美股期货；问「Killzone 对应 A 股几点」。

语言信号：A股 / 沪深 / 个股代码（600xxx/000xxx/300xxx/688xxx）/ 港股 / 台股 / 非美时段 / Killzone 对应几点 / A 股能用 ICT 吗 / 4 小时线（A 股语境下 = 日线）/ 为什么判不交易。

与相邻能力区分：
- 本能力只回答「**这个品种该用哪几轴、时间轴怎么处置**」，是前置分流门。
- 美股期货/外汇的时段与禁忌日判定 → `session-taboo-filter`（原书标定范围，本卡不接管）。
- 方向与依据链 → `daily-bias-checklist`；价位锚 → `daily-static-anchors`；流动性与下一目标 → `liquidity-dol-state-machine`；结构门 → `mss-displacement-gate`；缺口 → `fvg-three-candle`；入场区 → `ote-entry-zone`。
- Brooks 价格行为体系的概念（Always In、交易者方程、紧/宽通道、MTR、TBTL）→ 转介 `brooks-price-action-playbook`。

## E — Execution

**输入契约**

| 字段 | 类型 | 必需 | 说明 |
|---|---|---|---|
| 品种与市场 | 字符串 | 是 | 判定是否属原书标定范围；缺失先询问 |
| 数据粒度 | 字符串 | 是 | 日/周/月/分钟；决定 HTF 映射 |
| OHLC 序列 | 数据 | 是 | 价格轴与结构轴输入 |
| 本地事件日历 | 列表 | 否 | **不得预设**；缺失时标注「事件过滤未执行」 |

缺失品种或粒度时先询问，不得猜值。

**步骤**

1. **品种分流（前置门）**
   - `if 品种 ∈ 原书标定范围`（ES/NQ 等美股股指期货、主要外汇对）→ **本卡不适用**，转 `session-taboo-filter` 走完整三轴。
   - `elif 品种 ∈ A股/港股/其他非美时段市场` → 进入步骤 2。
   - `elif 品种 ∈ 24/7（加密货币、贵金属现货）` → 进入步骤 2，并额外声明原书明确未适配此类品种（`session-taboo-filter` B 段）。
   - 完成标准：输出品种归类与所走分支。

2. **时间轴处置：降级为「不适用」，禁止输出「不交易」**
   - 标记以下原书时间构件为**不可用**，逐项说明原因，不得静默跳过：
     - 五 Killzone 窗口（纽约时间标定，无本地对应）
     - 禁忌日清单（FOMC/NFP 为美国事件）
     - PO3 的 AMD 三段切分（按纽约时段）
     - Asian range 阈值 15–20 点（ES 点数口径）
     - 05:00 / 07:20 EST 开盘价规则（Ch25 p.508–514）
   - **关键判定**：输出「时间轴不适用（工具边界）」，**不得**输出「硬门失败 → 不交易」。这两者性质不同，混淆即为本卡要防止的错误。
   - 完成标准：不可用构件清单 + 明确的「不适用」标签。

3. **HTF 语义映射（约定，非原书）**
   - A 股全天交易时长正好 4 小时（9:30–11:30、13:00–15:00）→ **4H K 线 = 日线**，二者不构成跨周期关系。
   - 因此原书「日线/4H 作 HTF」在 A 股退化为单一层级；HTF 须改用**日线 + 周线**组合。
   - 本地事件日历（若用户提供）可替代性检查：仅登记用户明确给出的事件，**不预设任何本地禁忌日清单**（本流水线未验证任何本地事件规则）。
   - 完成标准：声明 HTF 采用哪两个周期，并标注该映射为约定。

4. **执行价格轴与结构轴（原书内容，完整可用）**
   - 价格轴：dealing range（严格定义：双边流动性都被扫过）→ EQ → 折价/溢价/均衡；流动性池按七类枚举（含 EQH/EQL）；未回补 FVG 清点；静态锚（PDH/PDL/PDC、周/月/年开盘价）。
   - 结构轴：MSS 必须带位移；位移未穿透结构 → MSS 不成立（核心原则第 3 条）。
   - DOL 按 ERL/IRL 交替规则输出下一目标；结合 HTF order flow 修正方向；两者冲突时**列出双方证据，不强行二选一**。
   - 完成标准：输出 DOL 类型 + 价位区间 + 依据 K 线；MSS 成立与否 + 依据。

5. **置信度降级与输出**
   - 输出必须含：`{品种归类, 时间轴状态: 不适用, 已执行轴: [价格, 结构], HTF映射约定, 偏向, 依据链, 失效条件, 置信标注: 降级}`。
   - 置信标注固定为**降级**，理由：丢失时段行为差异、事件回避、PO3 节奏三类信息。
   - 完成标准：输出不含「不交易」字样（除非价格轴/结构轴自身判停，如均衡区观望、无明确 DOL）。

**判停**

- 价格轴处于均衡区（当前价 ≈ EQ）→ 输出「最难预测，观望倾向」并判停（`daily-bias-checklist` 步骤 1）。
- 图上无未回补不平衡且无可见旧高低 → 输出「无明确 DOL」，不猜（`liquidity-dol-state-machine`）。
- 位移存在但未穿透结构 → MSS 不成立，不得输出反转确认（`mss-displacement-gate`）。
- 缺品种或数据粒度 → 先询问，不猜值。

## B — Boundary

- **本卡是迁移约定，不是原书方法**。第 2–5 节（时间轴降级、HTF 映射、置信度降级）均无原书依据，原书无任何非美时段市场内容。使用者须知悉：这部分规则的可靠性未经作者验证，也未经本流水线回测。
- **不预设本地事件禁忌日**。原书禁忌日是 FOMC/NFP 等美国事件；A 股对应的本地事件（利率、宏观数据、财报季、节假日）规则**本流水线未验证**，故不写入清单。用户提供时才登记，且标注为用户输入而非原书规则。
- **不禁止反向误用**：跳过时间轴会丢失 ICT 最有价值的部分。适配后的输出不得与美股品种的完整三轴输出同等对待，必须带「降级」标注。
- **点数与阈值不可迁移**：Asian range 15–20 点、ES 的 10pt 偏移（Ch25 p.508–514）等硬数字是 ES 口径，A 股无对应换算，本卡不提供（原书 `entry.out_of_scope` 已声明「不处理跨品种点数换算」）。
- **24/7 品种双重降级**：加密货币等品种原书明确未适配（`session-taboo-filter` B 段），叠加本卡的时间轴降级，置信度最低。
- **与 `session-taboo-filter` 互斥**：品种属原书标定范围时本卡不适用，必须转回该卡走完整时间轴；不得用本卡绕过美股品种的事件回避与硬门。
- 原书公理「价格只做两件事」未经证明（`liquidity-dol-state-machine` B 段），本卡不改变该前提；基本面驱动的单边行情可能长期不遵守 ERL/IRL 交替。
- 不输出幅度与时间预测；不提供投资建议或收益承诺。

## 实测记录（2026-10-25）

- 驱动来源：宁波韵升（600366.SH）日线实测。未适配时 ICT 输出「硬门不过 → 不交易」；适配后输出「偏向冲突 → 观望」+ 完整依据链 + 失效条件。
- 数据边界：行情接口仅提供日/周/月三张表（`ifind_stock_data_1day` / `_1week` / 月表）；**分钟级历史不可得**——60 分钟请求被降级改写为日线表且时间窗压缩，返回 0 行（已实测确认）。当日小时级走势仅支持当天查询。
- 连带结论：因分钟级不可得，A 股上无法执行任何依赖 LTF（1m–15m）的 ICT 能力（`ny-scalp-nine-step`、`opening-range-cpe`、`ict-atm-method` 的 LTF 触发段），只能用日线级别的结构与价位。
